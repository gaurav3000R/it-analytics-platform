# IT Analytics Platform - Frontend

A futuristic, AI-powered IT analytics platform built with Next.js 15, featuring real-time risk detection, project management, and comprehensive analytics dashboards.

## 🚀 Quick Start

```bash
cd frontend
npm install --legacy-peer-deps
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 📦 Tech Stack

- Next.js 15.5.2 + React 19
- TypeScript 5
- TanStack Query (React Query)
- Zustand for state management
- Tailwind CSS 4
- Framer Motion
- Recharts
- Radix UI Components

## 🎨 Features

✅ Real-time Dashboard with Live Metrics
✅ AI-Powered Risk Analysis
✅ Interactive Data Visualizations
