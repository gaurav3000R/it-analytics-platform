## 📝 Documentation Standards

### When to Update Documentation

Update documentation when you:
- Add new features or endpoints
- Change system architecture
- Modify setup or deployment processes
- Update dependencies or requirements
- Fix bugs that affect user workflows

### Documentation Best Practices

1. **Keep it Current**: Update docs with code changes
2. **Be Clear**: Write for beginners, not experts
3. **Use Examples**: Show, don't just tell
4. **Link Related Docs**: Help users navigate
5. **Format Consistently**: Follow existing patterns

### Documentation Template

When creating new documentation:

```markdown
# Title

## 📋 Overview
Brief description of what this covers

## 🎯 Purpose
Why this exists and who it's for

## 📚 Content
Main documentation content with:
- Clear headings
- Code examples
- Diagrams where helpful
- Links to related resources

## 🔗 Related Documentation
Links to other relevant docs
```
